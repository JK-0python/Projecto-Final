# Projecto-Final
El problema es que el cambio climatico esta afectando poco a poco nuestras vidas.
#
IDEA:
Bot de discord que te diga cosas sobre el cambio climatico y como arreglarlo.
#
El objectivo de este bot de discord es que la gente se de cuenta de como el cambio climatico afecta nuestras vidas y como arreglarlo.
#
Usuario:
El usuario va a poder poner un comando en discord y el bot le va a responder dependiendo del comando.
#
Ejemplo:
User: $climate_change_fact

Bot:🌍 Dato curioso: Los últimos 10 años han sido los más cálidos registrados en la historia, debido principalmente al calentamiento global causado 
por las actividades humanas.
